# Leveling

Manage Server to toggle. Message XP on by default when enabled; voice/reaction XP off until you turn them on in the dashboard.

```
!leveling enable
!leveling status
!leveling disable
```

Members: `!rank`, `!leaderboard`

Mods: [`!givexp`](/commands/moderation#cmd-givexp), [`!removexp`](/commands/moderation#cmd-removexp), [`!resetxp`](/commands/moderation#cmd-resetxp)

Rates, cooldowns, no-XP channels, level-up messages, level roles, and rank card
colors are in the dashboard. Keep ClaudeCityMod's role above reward roles.

- [`!leveling`](/commands/admin#cmd-leveling)
- [`!rank`](/commands/general#cmd-rank)
- [`!leaderboard`](/commands/general#cmd-leaderboard)
