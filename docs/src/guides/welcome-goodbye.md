# Welcome and goodbye

Manage Server required.

## Welcome

```
!welcome channel #welcome
!welcome on
!welcome test
```

`!welcome status` - current config

**Message placeholders:** `{user}` `{username}` `{server}` `{count}` `{role}`

**Card:** `!welcome image on|off`, `!welcome card preset|color|bgcolor|textcolor|greeting|background ...`

**Embed / DM:** `!welcome embed on|off`, `!welcome dm on|off`, `!welcome test dm`

**Trigger:** `!welcome trigger join` (default) or `!welcome trigger role`

## Goodbye

```
!goodbye channel #channel
!goodbye on
!goodbye message <text>
!goodbye test
```

`!welcome goodbye` also opens goodbye setup.

The dashboard exposes the same welcome and goodbye settings.

- [`!welcome`](/commands/admin#cmd-welcome)
- [`!goodbye`](/commands/admin#cmd-goodbye)
