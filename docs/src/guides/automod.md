# Automod

Manage Server required.

`!automod status` - current settings  
`!automod level <off|minimal|medium|high>` - preset

The same settings are available in the dashboard.

## Spam

- `!automod spam messages <count>`
- `!automod spam window <seconds>`
- `!automod spam violations <count>`
- `!automod spam timeout <minutes>`

## Links

- `!automod link deny <domain>`
- `!automod link allow <domain>`

## Ghost ping

`!automod ghostping on|off`

## Exempt

- `!automod exempt role add|remove @Role`
- `!automod exempt channel add|remove #channel`
