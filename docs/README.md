# ClaudeCityMod docs

VitePress documentation site for ClaudeCityMod. It is built separately from
the bot and is not required to run the bot or dashboard.

## Prerequisites

- Node.js 24+
- pnpm (same as the rest of the repo)

## Local development

From the **repo root**:

```bash
pnpm i
pnpm run docs:generate
pnpm run docs:dev
pnpm run docs:build
pnpm run docs:preview
```

Or from this directory:

```bash
pnpm i
pnpm run docs:generate
pnpm run docs:dev
```
