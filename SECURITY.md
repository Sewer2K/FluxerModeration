# Security policy

## Supported versions

Security updates are applied to the default branch and tagged releases as
appropriate. Use the latest release or `main` for production deployments when
possible.

## Reporting a vulnerability

**Please do not** file a public issue for undisclosed security problems.

Report vulnerabilities privately to the operator or maintainer of the
deployment you use. Include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept, if safe to share
- Affected versions or commits, if known

We will acknowledge receipt as soon as we can and work on a fix and coordinated
disclosure where applicable.

## Scope

In scope: this repository's bot code, API, and bundled dashboard as shipped
here. Out of scope: third-party services, the Fluxer platform, or issues that
require physical access to a server you control. Use standard server hardening
and secrets management.
